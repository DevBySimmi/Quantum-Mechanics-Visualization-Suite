# Quantum-Mechanics-Visualization-Suite
A Python-based visualization suite for exploring Quantum Tunneling, Wave Packet Evolution, and Quantum Harmonic Oscillator states using NumPy, Matplotlib, and SciPy.

## Features

### Quantum Tunneling
- Potential barrier visualization
- Energy level representation
- Wavefunction behavior inside and outside the barrier
- Probability density plot

### Wave Packet Evolution
- Time-dependent wave packet motion
- Real part of wavefunction
- Imaginary part of wavefunction
- Probability density evolution

### Quantum Harmonic Oscillator
- Energy eigenstates
- Hermite polynomial solutions
- Probability density distributions
- Classical turning points

## Technologies Used

- Python
- NumPy
- Matplotlib
- SciPy

## Installation

Install required libraries:

```bash
pip install numpy matplotlib scipy
```

## Run the Project

```bash
python quantum_mechanics_visualization.py
```

## Output

The program generates:

1. Quantum Tunneling Visualization
2. Wave Packet Evolution Graphs
3. Quantum Harmonic Oscillator States

This project was created for learning and visualizing fundamental concepts of Quantum Mechanics using Python.
